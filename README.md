# Blender Quantum Spark Field

A quantum-inspired procedural spark field created in Blender using Geometry Nodes.

# Overview

This project is a Blender scene designed to generate abstract spark flows
and glowing energy structures through procedural techniques.

Particles and curves behave like streams of quantum energy,
forming constantly shifting patterns driven by mathematical motion and field-based control.

The scene combines Geometry Nodes, emissive materials,
and procedural animation to create immersive sci-fi visuals.

It can be freely modified and used for learning Geometry Nodes,
motion design, procedural workflows, and visual experimentation.

## Features

- Quantum-inspired spark field system  
- Procedural Geometry Nodes workflow  
- Emissive glowing particle effects  
- Organic and evolving motion patterns  
- Customizable animation behavior  
- Suitable for sci-fi visual experiments  

# Software Requirement

Blender Version 3.4

# Blender Quantum Spark Field

Geometry Nodesを使用して制作された、
量子的なスパーク表現のBlenderシーンです。

# 概要

このプロジェクトは、
プロシージャル技術を用いて発光するスパークの流れや
エネルギー構造を生成するBlenderシーンです。

粒子やカーブは量子的なエネルギーの流れのように振る舞い、
数式的な動きやフィールド制御によって
常に変化し続けるパターンを形成します。

Geometry Nodes・発光マテリアル・プロシージャルアニメーションを組み合わせ、
SF的で没入感のあるビジュアルを実現しています。

Geometry Nodesの学習やモーションデザイン、
ビジュアル表現の実験用途として自由に活用できます。

## 特徴

- 量子的なスパークフィールド表現  
- Geometry Nodesベースの構成  
- 発光する粒子エフェクト  
- 有機的で変化し続ける動き  
- アニメーション挙動を自由に調整可能  
- SFビジュアル実験に最適
